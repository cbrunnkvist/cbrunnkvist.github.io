@openrai/nano-core + rspow + Standards. Typed protocol primitives, PoW, snapshot distribution, and compatibility guidelines for the Nano mesh.

## What it is

`@openrai/nano-core` is the protocol foundation layer: addresses, amounts, RPC access, WebSocket handling, local proof-of-work, precision math, and compatibility-focused helpers.

## Why it matters

Nano projects often rebuild small pieces of protocol handling over and over. This gives application code a shared, typed substrate so wallet and payment experiments can move faster.

## Current angle

This project should eventually read like polished protocol documentation: practical examples first, then deeper implementation notes.
